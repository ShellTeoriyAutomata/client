# Лабораторная работа по теории автоматов

Приложение на React и TypeScript с Vite и Electron. Студент выполняет задание по грамматике: задаёт нетерминалы и их терминальные значения, составляет шаблон и проверочное слово, затем оценивает переходы по одному. Преподаватель управляет группами и заданиями и просматривает результаты.

## Ввод символов студентом

- Нетерминалы: только заглавные английские буквы `A–Z`. Допустимы составные имена, например `NUM`. Пример ввода: `A\B\C\NUM`. Количество не ограничено; нетерминалы можно повторять в шаблоне сколько угодно раз.
- Терминалы для каждого нетерминала: русские буквы обоих регистров (включая `Ё` и `ё`), цифры, диапазоны `А-Я`, `а-я`, `0-9` и epsilon (`_` или `ε`). Русские диапазоны включают букву Ё.
- Разделитель значений — обратная косая черта `\`. Пробелы по краям значения игнорируются.
- Русские буквы и строчные английские буквы в нетерминалах, английские буквы в терминалах отклоняются при нажатии «Далее». Обратные диапазоны (`я-а`, `9-0`) и диапазоны смешанного регистра (`А-я`) также отклоняются.
- `_` означает пустое значение: он не добавляет символ в слово и не заменяет пробел. Например, для `A = а\_` шаблон `A` допускает `а` и пустое слово, вводимое как `_`.
- Каждое неверное значение при проверке и каждый неверный выбор действия учитывается отдельной ошибкой. Пустое поле — одна ошибка. Повторная отправка неверного значения добавляет новую ошибку; исправление не сбрасывает счётчик.

## Проверка адреса и переходов

Каждое вхождение нетерминала обозначает одну допустимую букву, цифру или epsilon и создаёт отдельную строку перехода. Назначать нетерминал всему полю не нужно. Например, `BAAAA` — пять символов, а `CCC` — три цифры. Несколько нетерминалов могут задавать символы одного поля; один нетерминал можно использовать в разных полях.

Для русских букв обоих регистров задайте `а-я\А-Я` или нажмите кнопку «а-я и А-Я» рядом с определением. Если регистры заданы отдельно (`A = а-я`, `B = А-Я`), они проверяются согласно этим определениям.

Поля адреса распознаются по подписям `ул.`, `д.`, `кв.` (также `улица`, `дом`, `квартира`) и запятым:

| Поле | Ограничение | Пример нетерминала и терминалов |
| --- | --- | --- |
| Улица | 5–10 русских букв любого регистра | `A = а-я`, `B = А-Я` |
| Дом | Ровно 3 цифры | `C = 0-9` |
| Квартира | Ровно 2 цифры | `D = 0-9` |

Пример шаблона: `ул. BAAAA, д. CCC, кв. DD`. Корректное слово: `ул. Лепсе, д. 444, кв. 52`. В симуляции будут отдельные переходы `B → Л`, четыре перехода `A` для `епсе`, три перехода `C` для `444` и два перехода `D` для `52`, а также переходы буквальных разделителей. Ведущие нули в номерах сохраняются.

Адрес и последовательность нетерминалов можно ввести в обратных полях: если только второе поле содержит известные нетерминалы, оно автоматически считается шаблоном. Распознанные шаблон и слово отображаются в симуляции и сохраняются в результате. `Task.grammarMode = 'address'` обозначает встроенную адресную лабораторную; ограничений на число нетерминалов или их повторения это поле не вводит.

Проверка различает короткую и длинную улицу, короткий и длинный дом, короткую и длинную квартиру, недопустимые символы, преждевременный конец слова и лишний ввод. Ошибки в разных полях проверяются отдельно. Некорректное проверочное слово учитывается в счётчике, но остаётся доступным для обучения распознаванию ошибок на отдельных шагах. Ответы будущих шагов не показываются.

На каждом шаге видны шаблон, проверочное слово, оставшийся магазин (вершина слева) и указатели текущих позиций. Студент оценивает только одну триаду `(состояние, символ слова, вершина магазина)` и выбирает действие из готового набора:

| Действие | Когда выбирать |
| --- | --- |
| `pop` | Сопоставление верно; перейти дальше. Также подтверждает успешный конец слова и магазина. |
| `input-short` | Слово или поле короче требуемого, закончилось раньше. |
| `input-long` | Слово или поле длиннее требуемого, остались лишние символы. |
| `mismatch` | Символ не соответствует заданному нетерминалу или буквальному символу. |

Всего три встроенные ошибки; создавать и называть их не нужно. Приложение проверяет выбор при нажатии «Проверить переход». Неверный ответ увеличивает счётчик, сохраняет текущую триаду и позиции указателей. Верный ответ сдвигает указатели, обновляет магазин, добавляет переход в историю и открывает следующую триаду. При epsilon указатель слова не сдвигается. На границе адресного поля возможна проверка его длины с виртуальной epsilon-вершиной; после классификации ошибки проверка продолжается со следующего поля.

Завершение определяется автоматически; отдельного действия `OK` или прочерка в списке нет. После проверки всех переходов доступна кнопка «Завершить и сохранить». Новая симуляция начинает проверку с первого перехода и сбрасывает ответы, сохраняя общий счётчик ошибок лабораторной.

API симуляции: `getGrammarActions()` возвращает `pop` и три ошибки; `getTransitionErrors(rows, answers)` проверяет встроенные действия. `simulateGrammar()` возвращает `templateTokens`, `wordSymbols` и шаги с `templateIndex`, `inputOffset`, `stack` для отображения указателей и магазина.

## Результаты преподавателя

Счётчик виден во время работы, на итоговом экране и в списке результатов преподавателя. В деталях результата показываются история ошибок и журнал всех этапов, включая пошаговые ответы. После правильной оценки всех переходов результат сохраняется даже для отклоняемого проверочного слова: выполнение лабораторной и принятие слова показываются отдельно.

В `Result` добавлены необязательные поля `mistakeCount` (счётчик), `errorHistory` (история) и `wordAccepted` (принято ли слово). Старые результаты остаются читаемыми; отсутствующие значения не подменяются нулём.

## Проверка изменений

Для просмотра и отладки в браузере:

```sh
npm run dev
```

Откройте локальный адрес, напечатанный Vite (обычно `http://localhost:5173/`). Оставьте терминал работающим; изменения кода отображаются автоматически. Создание EXE и Wine для этого не нужны.

Для тестов и сборки веб-приложения:

```sh
npm ci
npm test
npm run build
```

## Приложение Windows

```sh
npm run electron:pack:win
```

Результат: `release/Automata-Setup-0.0.0.exe`. Установите приложение один раз, затем открывайте ярлык **Automata** на рабочем столе или в меню «Пуск». Подробности сборки и запуска описаны в [DEPLOYMENT.md](DEPLOYMENT.md).
