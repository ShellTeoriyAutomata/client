# Сборка и установка Automata для Windows

## Сборка

На компьютере разработчика используйте Node.js 22 LTS или новее и npm. На компьютере студента Node.js и npm не нужны.

```sh
npm ci
npm run electron:pack:win
```

Команда запускает тесты, собирает React/Vite и создаёт установщик NSIS для Windows x64. `npm run electron:pack` выполняет ту же сборку Windows. При первой сборке требуется интернет для загрузки Electron для Windows и компонентов NSIS. Для сборки на Linux дополнительно требуется Wine с поддержкой 32-битных Windows-программ. Если Wine отсутствует, команда сразу завершится с объяснением и командой локального запуска, до запуска сборки и скачиваний.

Результаты в `release/`:

- `Automata-Setup-0.0.0.exe` — установщик для распространения. Номер соответствует версии в `package.json`.
- `win-unpacked/Automata.exe` — исполняемый файл приложения для проверки сборки. Ему нужна вся папка `win-unpacked`, включая `resources`; нельзя распространять этот файл отдельно.

Сертификат цифровой подписи в проекте не настроен. Для подписанных релизов потребуется отдельная настройка сертификата и сборочного окружения.

## Установка и ежедневный запуск

1. Один раз запустите `Automata-Setup-0.0.0.exe` и пройдите мастер установки. Можно выбрать каталог установки.
2. После установки открывайте **Automata** с ярлыка на рабочем столе или из меню «Пуск». Приложение запускается из постоянного каталога установки.
3. Для последующих запусков открывайте ярлык приложения. Повторный запуск файла `Automata-Setup-0.0.0.exe` снова открывает установщик.

Установленное приложение загружает файлы из своей сборки. Сервер Vite и интернет для выполнения лабораторной не нужны. Инструменты разработчика автоматически не открываются.

## Данные и обновления

Группы, задания и результаты хранятся локально в профиле Electron текущего пользователя Windows. Данные сохраняются между запусками. У разных учётных записей Windows отдельные данные.

Для обновления увеличьте версию в `package.json` и `package-lock.json`, соберите новый установщик и запустите его на установленном приложении. Сохраняйте `appId` (`com.automata.app`), имя пакета (`automata`) и `productName` (`Automata`), чтобы сохранялась идентичность установки и профиля. Удаление приложения не удаляет данные пользователя (`deleteAppDataOnUninstall: false`).

## Разработка

Для просмотра и отладки в браузере на Linux или Windows:

```sh
npm run dev
```

Откройте адрес из вывода Vite (обычно `http://localhost:5173/`). Оставьте терминал работающим. Для этого не нужны EXE и Wine.

Для запуска окна Electron:

```sh
npm run electron
```

Эта команда запускает Vite и окно Electron с инструментами разработчика.

Настройки установщика: [официальная документация electron-builder / NSIS](https://www.electron.build/docs/nsis/).
