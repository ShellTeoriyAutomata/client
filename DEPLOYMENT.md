# Гайд по развертыванию (Deployment Guide)

## 1. Подготовка окружения

Убедитесь, что у вас установлен [Node.js](https://nodejs.org/).

## 2. Установка зависимостей

Перед началом работы или сборкой необходимо установить библиотеки проекта:

```bash
npm install
```

## 3. Запуск в режиме разработки

Для работы над проектом локально (с горячей перезагрузкой):

```bash
npm run electron
```

Эта команда запустит локальный сервер Vite и откроет окно Electron.

## 4. Сборка для "Продакшена" (Создание .exe)

Чтобы создать готовый установщик для распространения:

```bash
npm run electron:pack
```

### Что происходит при сборке?

1. Выполняется `npm run build`: React/Vite собирает веб-часть приложения в папку `dist/`.
2. Запускается `electron-builder`: Он берет файлы из `dist/` и `electron/`, упаковывает их и создает установщик Windows.

### Где найти результат?

После успешного выполнения команды, загляните в папку **`release/`**.
Там вы найдете файл вида `Automata Setup X.X.X.exe`.

**Этот файл `.exe` и есть ваш "деплой". Вы можете скинуть его кому угодно, и они смогут установить вашу программу.**
